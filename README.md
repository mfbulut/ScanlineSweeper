# ScanlineSweeper
An implementation of Scanline Sweeper algorithm by [Rook & Possum](https://rookandpossum.com/posts/scanline-sweeper/)

* Paper: [PDF Link](https://rookandpossum.com/papers/scanline_sweeper_preprint.pdf)
* Video: [YouTube Link](https://www.youtube.com/watch?v=B9bztU1sTFA)

--- 

Run the demo
```
odin run .
```

Generate fonts
```
odin run ./assets/fonts/
```

Compile shaders
```
./assets/shaders/compile.bat
```
